# InsilicoMediaDesign

In-silico design and optimization of cell-culture media for cellular agriculture.

## Goal

Replace expensive, animal-derived components (notably fetal bovine serum) in cell-culture media with cheaper, defined formulations — using computational methods to narrow the experimental search space before any wet-lab work.

## Scope (initial)

- Survey existing media-optimization literature and datasets
- Reproduce baseline Bayesian-optimization approaches (Cosenza et al. 2022, 2023)
- Evaluate where LLMs and foundation models add leverage beyond classical BO:
  - Literature-grounded ingredient suggestion
  - Protein-LM-driven design of recombinant growth factors
  - Agentic experiment-design loops
